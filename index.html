How this was put together

concept · Aug 2026

Everything on this page runs in your browser. There is no server behind it and nothing is sent anywhere. It exists to show one flow end to end rather than describe it.

Compose for TVThe interface is laid out the way an Android TV build would be, at the panel's own 3:2 geometry so nothing is letterboxed.Interface
Phone firstPhoto selection happens on a phone because that is the only place Google allows it since March 2025. The frame shows a code and waits.Photos
PairingA six digit code with a short lifetime, one live challenge at a time, and a lockout after repeated failures. The phone receives a token scoped to the device, never a user session.Security
Three transportsLocal discovery for speed, a relay for when the phone is elsewhere, Bluetooth for the state before any network exists.Remote
Offline firstThe album being played is held on the device, so losing the network changes nothing on the wall.Storage
No spinnerThe next image is decoded while the current one is still up. A loading indicator on a wall reads as a fault, not as patience.Detail
Generated artworkEvery image here is drawn in your browser from gradients and shapes. No photograph belongs to anyone, and nothing has been copied from any gallery.Imagery
